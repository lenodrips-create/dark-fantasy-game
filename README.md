# Forest Starting Level

Third-person browser game written in C with [raylib](https://www.raylib.com/), compiled to WebAssembly with Emscripten.

- `c_game/src/main.c` — the game
- `c_game/assets/` — level (exported from `forest_ground.blend`), knight model, textures
- `c_game/build.sh` — builds to `game/` (served by GitHub Pages)

Controls: WASD move, Shift run, Space jump, mouse look (click to capture), wheel zoom, Esc pause.
